# Chat de Soporte Genérico Alloxentric

Proyecto de título orientado al desarrollo de una plataforma multi-tenant de soporte conversacional para los clientes de Alloxentric.

La solución propuesta contempla un módulo de administración, chat web y WhatsApp, agentes de soporte técnico y comercial basados en RAG, y derivación a agentes humanos cuando sea necesario.

## Estado

Proyecto en etapa inicial. La planificación, el alcance definitivo y las decisiones técnicas se irán documentando de acuerdo con los lineamientos académicos y las reuniones de seguimiento.

## Estructura académica

El repositorio está organizado en tres fases, cada una con sus respectivas evidencias individuales, grupales y de proyecto.
